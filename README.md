# Healthcare Analytics Dashboard

## Project Overview
This project analyzes healthcare encounter, coverage, cost, and patient behavior data using Power BI.

## Objectives
- Analyze encounter trends over time.
- Evaluate payer coverage and claim costs.
- Identify patient readmission patterns.

## Tools Used
- Power BI
- DAX
- Healthcare Dataset

## Key Insights
- Most encounters lasted less than 24 hours.
- Ambulatory encounters represented the largest encounter class.
- Nearly 14K encounters had no payer coverage.
- ICU admissions had the highest average procedure cost.
- Approximately 17K readmissions occurred within 30 days.
